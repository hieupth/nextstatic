Components

Swap the plain tag for the wrapper of the same name — same props, no prefix to remember. <Image src="/img/logo.svg" /> resolves to the prefixed URL automatically. Everything below runs live on this page.

Link / Anchor

Link wraps next/link; basePath comes from Next, the locale segment from LocaleProvider. Anchor is the raw <a> form.

<Link href="/about">About</Link>
<Anchor href={`/en/docs/`}>Docs (internal)</Anchor>
AboutDocs (internal anchor)example.com

Image / Bg

<Image src="/img/logo.svg" width={120} height={120} />
<Bg backgroundImage="/img/pattern.svg">…</Bg>
Bg — backgroundImage

Script

Loads /js/demo.js with the basePath applied after hydration.

<Script src="/js/demo.js" strategy="afterInteractive" />
Open the browser console — demo.js logs a message when it loads. console.log("demo.js loaded from prefixed path")

Media: Video / Audio / Iframe

<Video src="/media/flower.mp4" poster="/img/pattern.svg" controls />
<Audio src="/media/t-rex-roar.mp3" controls />

Video

Local file — the URL gets the prefix — /media/flower.mp4. The poster is prefixed too.

External URL — left untouched

Audio

Local file — the URL gets the prefix — /media/t-rex-roar.mp3

External URL — left untouched

Iframe

Picture / Source

<Source> prefixes src and every srcSet candidate; descriptors (1x, 2x…) are preserved.

<picture>
  <Source srcSet="/img/logo.svg 1x, /img/pattern.svg 2x" />
  <img src={getPrefixPath("/img/logo.svg")} alt="logo" />
</picture>

Form

<Form action={`/en/docs/`}>
  <input name="q" />
  <button type="submit">Search</button>
</Form>

The action URL gets the basePath — this one submits to the docs page.
