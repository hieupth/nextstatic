Thiết lập

Bốn bước từ số 0 tới một site static có prefix đúng.

Cài đặt gói

terminal
npm install @hieupth/nextstatic

Next.js 16.3 trở lên dùng static export (output: "export") · React 18 hoặc 19 · Node.js 22 trở lên

Chọn BASE_PATH

BASE_PATH là phần URL nằm giữa tên miền và ứng dụng của bạn. Nó phải khớp với nơi bạn host — bảng dưới liệt kê các trường hợp thường gặp.

Kiểu hostingURL trangBASE_PATH
Gốc domain riêng của bạnhttps://my-site.com/""
GitHub Pages project sitehttps://user.github.io/repo/"/repo"
Thư mục con (như preview này)https://host/demo/"/demo"

Trên GitHub Actions có thể suy ra từ GITHUB_REPOSITORY — xem next.config.ts của chính repo này cho snippet sẵn dùng.

next.config.ts (CI)
const inferBasePath = (): string => {
  if (process.env.BASE_PATH !== undefined) return process.env.BASE_PATH;
  if (process.env.GITHUB_REPOSITORY)
    return `/${process.env.GITHUB_REPOSITORY.split("/")[1]}`;
  return "";
};

Kết nối next.config.ts

Cùng một giá trị phải đến cả Next (basePath) lẫn thư viện (env) — đó là toàn bộ hợp đồng “phải khớp nhau”. Khối env inline giá trị vào client bundle để thư viện đọc đúng prefix lúc chạy.

next.config.ts
const basePath = process.env.BASE_PATH ?? "";

const nextConfig = {
  // static files only — no Node server needed
  output: "export",
  // /about/ style URLs → about/index.html on disk
  trailingSlash: true,
  // Next prefixes its own chunks & routes…
  basePath,
  assetPrefix: basePath,
  images: { unoptimized: true },
  // …and the env block inlines the value so the lib
  // reads the SAME prefix at runtime
  env: {
    BASE_PATH: basePath,
    NEXT_PUBLIC_BASE_PATH: basePath,
  },
};

Build và kiểm chứng

Build với đường dẫn cơ sở
BASE_PATH=/demo npm run build

Mở site sau build — footer hiển thị BASE_PATH đang chạy, và mọi ảnh phải load dưới prefix đó.

Chỉ cần vậy thôi. Mọi thứ còn lại được wrapper xử lý.
