nextstatic

The path & asset layer for Next.js static exports under a sub-directory. This app is the living documentation and verification harness.

Read the docsSee components live

Drop-in wrappers

Image, Script and media wrappers apply the basePath automatically; Link handles the locale segment (Next adds the basePath).

Flicker-free i18n

The locale lives in the route and each language prerenders its own HTML — no client-side flash.

Zero-config utils

Plain functions for raw surfaces: plain <a>, <img> tags and CSS url() values.
